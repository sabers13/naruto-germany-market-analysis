# Accuracy check outputs

- `precision.csv`: keyword-match precision per source and character (Wilson 95% intervals) and the resulting treatment (`use`, `adjust`, `exclude`; rules in `ANALYSIS_PLAN.md` §6). Kleinanzeigen rows are left out, as its figures are not published.
- `independent_spotcheck.md`: summary of a blind second labelling of a 72-item subset.

The labelled samples (one row per checked match, keyed by record hash) stay local: they are row-level working data and are not part of this repository. No snippets are kept anywhere.
